## ⚡ Key Features

- **Multi-Platform Deployment:** Auto-detects Claude Code, OpenCode CLI, Agent Standard (`~/.agents`), Cursor, and Windsurf.
- **Rule Conflict Linter:** Catches clashing CSS, shadow, and platform directives before they corrupt model reasoning.
- **Token Budget Profiler:** Calculates exact BPE token cost and context window percentage.
- **Tiered Hybrid Architecture:** 8 Master Hubs (`/hub-*`) and 6 Workflow Strike Teams (`/pack-*`).
